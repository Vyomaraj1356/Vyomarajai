🛠️ Build Instructions

Android — Build APK

./gradlew assembleDebug → app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease (needs my-upload-key.jks env).
Or just use the prebuilt 24.8 MB APK above.

Mac — Build App

cd macos-v5 && swift build -c release
or Xcode: open Package.swift → Run (⌘R).
Zip is at /Vyomaraj-Mac.zip and /macos-v5/dist.

Web — Build & Deploy

cd web-v5 && npm run build → dist/ (GitHub Pages base /Vyomaraj-Agent/).
node web_server.js → :3000 serves landing + APK.
node control-plane/src/server.mjs → :8080 API.

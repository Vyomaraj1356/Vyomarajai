# VYOMARAJ SECURITY PROTOCOL
DETECT → PRESERVE EVIDENCE → CONTAIN → VERIFY → RECOVER → RECHECK → RESUME

Roles:
- VYOMARAJ: control-plane authority.
- JARVIS: orchestration, continuity and incident coordination.
- ARENA: implementation and preview execution; must not weaken security or DR controls.
- CHATGPT: research, architecture, diagnosis and verification support.

Rules:
1. Historical claims, screenshots and commit messages are not proof.
2. Never expose credentials in reports, commits, logs or chat.
3. If compromise is suspected, do not blindly replicate or promote.
4. Never execute untrusted archives or suspicious files.
5. Automatic deletion, force-push and DR-to-Primary promotion remain disabled.
6. Primary/DR SHA equality proves branch equality only; it does not prove application integrity.
7. Missing evidence must be marked UNVERIFIED or UNRECOVERED — SOURCE NOT AVAILABLE.

Incident handoff:
FACTS / EVIDENCE / CHANGES / FINDINGS / CONTAINMENT / RECOVERY STATE / VERIFICATION / REMAINING RISK

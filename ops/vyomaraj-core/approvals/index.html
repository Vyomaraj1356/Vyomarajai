TAKE THE APPROPRIATE ACTION

This checkout has no token issuer configured. The first request returns the exact action target; only a trusted external passkey/WebAuthn issuer may sign it. The token is sent only with the action request and is not written to browser storage or the audit log.

Approve records a local owner decision for a separate publishing gate; it never publishes or schedules publishing. Rework/submit only store local instructions; they do not message an agent. Notification delivery and agent handoff are not implemented.

How this gate fits the governing principle
  • You (Owner) hold authority through ShriYantra; Vyomaraj/Bharath is the central intelligence and Jarvis/Laxman moves and coordinates content.
  • Agents create and verify; only owner-approved work reaches publishing; Hermes guards integrity and recovery across the whole path.
  • Arena executes approved tasks — it is not the owner and not the authority root.
  • Finance and audit follow-up and morning briefings: /finance/. Post-deployment changes with rollback: /upgrades/.
